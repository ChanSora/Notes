## 第一部分：化合物命名规则

| 化学式 | 中文名 | 英文名 | 规则 |

| SO₃ | 三氧化硫 | sulfur trioxide | 同上 |

### 十、命名规则速查表

1. **无机共价分子（非金属-非金属）**：数字前缀 + 元素名（第二元素改 -ide）
2. **金属氧化物 / 盐（可变价金属）**：金属名 + (氧化态罗马数字) + 阴离子名
3. **含氧酸**：-ate → -ic acid；-ite → -ous acid；per-...-ate → per-...-ic acid；hypo-...-ite → hypo-...-ous acid
4. **无氧酸**：hydro- + 非金属词根 + -ic acid（对应盐的阴离子为 -ide）
5. **酸式酸根（含氢）**：hydrogen-（或 dihydrogen-）+ 酸根名（传统可用 bi-）
6. **有机化合物（IUPAC）**：官能团词尾 + 碳数前缀 + 取代基（按字母顺序）
7. **族别名识别要点**：碱金属、碱土金属、卤素、稀有气体必须掌握；氮族、氧族常用于含氧酸命名；过渡金属族别名主要用于性质描述，命名时仍用 Stock 法

## 第二部分：化学方程式常用术语

### 十二、反应符号与状态标识

| 符号 | 英文术语 | 中文含义 | 示例 |
|------|----------|----------|------|
| → | yields / gives / forms | 生成、得到 | CH₄ + O₂ → CO₂ + H₂O |
| ⇌ | equilibrium | 可逆、平衡 | N₂ + 3H₂ ⇌ 2NH₃ |
| ↑ | gas evolved | 气体逸出 | Zn + 2HCl → ZnCl₂ + H₂↑ |
| ↓ | precipitate forms | 沉淀生成 | Ag⁺ + Cl⁻ → AgCl↓ |
| (s) | solid | 固体 | NaCl(s) |
| (l) | liquid | 液体 | H₂O(l) |
| (g) | gas | 气体 | O₂(g) |
| (aq) | aqueous (solution) | 水溶液 | HCl(aq) |
| (ppt) | precipitate | 沉淀（旧用） | AgCl(ppt) |

### 十三、反应类型术语

| 英文术语 | 中文 | 说明 |
|----------|------|------|
| synthesis / combination | 化合反应 | A + B → AB |
| decomposition | 分解反应 | AB → A + B |
| single displacement / substitution | 置换反应 | A + BC → AC + B |
| double displacement / metathesis | 复分解反应 | AB + CD → AD + CB |
| combustion | 燃烧反应 | 通常指与 O₂ 反应 |
| redox / oxidation-reduction | 氧化还原反应 | 电子转移 |
| precipitation | 沉淀反应 | 生成不溶物 |
| neutralization | 中和反应 | 酸 + 碱 → 盐 + 水 |
| hydrolysis | 水解反应 | 盐与水反应 |
| dissociation | 电离 | 电解质溶于水产生离子 |
