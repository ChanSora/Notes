# 带电粒子在磁场中受到的作用

## 一、核心公式：洛伦兹力

运动电荷在磁场中受到的力称为**洛伦兹力**，公式为：

$$ \mathbf{F} = q \mathbf{v} \times \mathbf{B} $$

其中：
- $q$：粒子的电荷量（可正可负）
- $\mathbf{v}$：粒子的速度矢量
- $\mathbf{B}$：磁感应强度矢量

### 洛伦兹力的特点

1. **方向特性**：力的方向始终垂直于 $\mathbf{v}$ 和 $\mathbf{B}$ 所确定的平面，由右手定则判断（正电荷方向，负电荷相反）。
2. **不做功**：因为 $\mathbf{F} \perp \mathbf{v}$，所以洛伦兹力对粒子**不做功**，只改变速度方向，不改变速度大小。
3. **与电场力对比**：电场力 $\mathbf{F}_e = q \mathbf{E}$ 可以做功，改变粒子动能；洛伦兹力只改变运动方向。

## 二、带电粒子在均匀磁场中的运动轨迹

设磁场 $\mathbf{B}$ 均匀且恒定，初始速度 $\mathbf{v}$ 与 $\mathbf{B}$ 的夹角为 $\theta$，将速度分解为：
- 平行分量：$v_\parallel = v \cos\theta$
- 垂直分量：$v_\perp = v \sin\theta$

### 2.1 三种典型情况

| 初始条件 | 运动轨迹 | 说明 |
| :--- | :--- | :--- |
| $\mathbf{v} \parallel \mathbf{B}$（$\theta = 0^\circ$） | 匀速直线运动 | 洛伦兹力为零，$v_\parallel$ 不变 |
| $\mathbf{v} \perp \mathbf{B}$（$\theta = 90^\circ$） | 匀速圆周运动 | 洛伦兹力提供向心力 |
| $\mathbf{v}$ 与 $\mathbf{B}$ 成任意角（$0^\circ < \theta < 90^\circ$） | 等距螺旋线运动 | 圆周运动 + 匀速直线运动的合成 |

### 2.2 关键参数公式

| 参数          | 公式                                                 | 说明 |
| :---------- | :------------------------------------------------- | :-- | 
| 回旋半径（圆周运动）  | $$ R = \frac{m v_\perp}{                            q    B} $$         | $m$：粒子质量             |
| 回旋周期        | $$ T = \frac{2\pi m}{                               q    B} $$         | 与 $v_\perp$ 和 $R$ 无关 |
| 回旋频率（回旋加速器） | $$ f = \frac{                                       q    B}{2\pi m} $$ | 又称**拉莫尔频率**          |
| 螺距（螺旋运动）    | $$ h = v_\parallel T = \frac{2\pi m v \cos\theta}{  q   B} $$         | 螺旋线相邻两圈间的轴向距离        |
## 三、磁偶极子
### 3.1 磁偶极矩的定义
一个平面电流回路所围成的区域构成一个**磁偶极子**，其磁偶极矩 $\mathbf{m}$ 定义为：
$$ \mathbf{m} = I \mathbf{S} \cdot \mathbf{n} $$
其中：
- $I$：回路中的电流强度
- $S$：回路所围面积
- $\mathbf{n}$：回路平面的法向单位矢量，方向由右手定则确定（弯曲四指沿电流方向，拇指指向即为 $\mathbf{m}$ 方向）
对于单匝线圈，$m = I \cdot S$；对于 $N$ 匝密绕线圈，$m = N I S$。
### 3.2 磁偶极子在均匀磁场中受到的力矩
当磁偶极子处于均匀外磁场 $\mathbf{B}$ 中时，所受合力为零，但受到一个**磁力矩**的作用，使其转向外磁场方向：
$$ \boldsymbol{\tau} = \mathbf{m} \times \mathbf{B} $$
力矩大小为 $\tau = m B \sin\theta$，其中 $\theta$ 为 $\mathbf{m}$ 与 $\mathbf{B}$ 的夹角。
力矩的势能（磁偶极子在磁场中的势能）：
$$ U = -\mathbf{m} \cdot \mathbf{B} = -m B \cos\theta $$
稳定平衡位置：$\mathbf{m} \parallel \mathbf{B}$（$\theta = 0$，势能最小 $U_{\text{min}} = -mB$）  
不稳定平衡位置：$\mathbf{m} \parallel -\mathbf{B}$（$\theta = \pi$，势能最大 $U_{\text{max}} = +mB$）
### 3.3 磁偶极子在不均匀磁场中受到的力
在不均匀磁场 $\mathbf{B}(\mathbf{r})$ 中，磁偶极子会受到一个净力：
$$ \mathbf{F} = \nabla (\mathbf{m} \cdot \mathbf{B}) $$
对于 $\mathbf{m}$ 方向固定的情况（如顺磁质），力可近似为：
$$ F_x \approx m \frac{\partial B_x}{\partial x} $$
**重要推论**：磁偶极子会被**磁场增强的方向**吸引（即被强磁场区域吸引）。
### 3.4 磁偶极子产生的磁场
位于原点的磁偶极子 $\mathbf{m}$ 在空间 $\mathbf{r}$ 处产生的磁感应强度：
$$ \mathbf{B}(\mathbf{r}) = \frac{\mu_0}{4\pi} \left[ \frac{3(\mathbf{m} \cdot \hat{\mathbf{r}}) \hat{\mathbf{r}} - \mathbf{m}}{r^3} \right] $$
与电偶极子的电场公式形式完全相同，因此磁偶极子与电偶极子的场线分布图也完全相同。
### 3.5 磁偶极矩的微观起源
- **轨道磁矩**：电子绕核运动等效为环形电流，$m_{\text{orbital}} = \frac{e}{2m_e} L$（$L$ 为轨道角动量）
- **自旋磁矩**：电子自旋产生的内禀磁矩，$m_{\text{spin}} = \frac{e}{m_e} S$（$S$ 为自旋角动量）
- **玻尔磁子**：原子磁矩的基本单位，$$\mu_B = \frac{e\hbar}{2m_e} \approx 9.27 \times 10^{-24} \, \text{J/T}$$
## 四、应用实例

### 4.1 速度选择器

$\mathbf{E}$ 和 $\mathbf{B}$ 相互垂直，当 $qE = qvB$ 即 $v = E/B$ 时，粒子沿直线通过。

### 4.2 质谱仪
利用不同粒子的 $ m/q $ 不同导致偏转半径不同，公式为：$$ R = \frac{mv}{qB} = \frac{\sqrt{2mK}}{qB} $$（$K$ 为动能）

### 4.3 回旋加速器
利用交变电场加速和磁场偏转，最终出射能量：$$ E_{\text{max}} = \frac{q^2 B^2 R_{\text{max}}^2}{2m} $$

### 4.4 磁聚焦
从同一点以不同角度发射的粒子，若 $v_\parallel$ 相近，经过一个周期后会重新汇聚到一点。

## 五、霍尔效应

当载流导体/半导体处于垂直于电流方向的磁场中时，会在垂直于电流和磁场的两侧产生横向电势差——**霍尔电压**：

$$ U_H = \frac{IB}{nqd} $$

其中：
- $n$：载流子浓度
- $d$：导体沿磁场方向的厚度
- $q$：载流子电荷

**意义**：可用于判断载流子类型（电子或空穴）和测量磁场强度。

## 六、总结对比表

| 物理量/规律 | 公式 | 适用条件 |
| :--- | :--- | :--- |
| 洛伦兹力 | $\mathbf{F} = q \mathbf{v} \times \mathbf{B}$ | 任何运动电荷 |
| 回旋半径 | $R = \frac{mv_\perp}{\|q\|B}$ | 均匀磁场，$\mathbf{v} \perp \mathbf{B}$ |
| 回旋周期 | $T = \frac{2\pi m}{\|q\|B}$ | 均匀磁场，$\mathbf{v} \perp \mathbf{B}$ |
| 霍尔电压 | $U_H = \frac{IB}{nqd}$ | 稳态霍尔效应 |
| 速度选择器 | $v = \frac{E}{B}$ | $\mathbf{E} \perp \mathbf{B}$ |
# “电生磁”模块核心总结

## 一、 核心公式（麦克斯韦方程组·静磁形式）

1.  **毕奥-萨伐尔定律**（最普遍，任意载流导线）
    $$d\mathbf{B} = \frac{\mu_0}{4\pi} \frac{I d\mathbf{l} \times \mathbf{r}}{r^3}$$
    - 物理意义：电流元产生磁场的定量规律，需积分求解总场。

2.  **安培环路定律**（最简洁，高度对称分布）
    $$\oint_L \mathbf{B} \cdot d\mathbf{l} = \mu_0 I_{\text{enc}}$$
    - 适用条件：稳恒电流，且电流分布具有无限长、无限大等严格对称性。

3.  **运动电荷的磁场**（微观形式）
    $$\mathbf{B} = \frac{\mu_0}{4\pi} \frac{q \mathbf{v} \times \mathbf{r}}{r^3}, \quad v \ll c$$

4.  **磁场对电荷/电流的作用力**
    - 洛伦兹力：$$\mathbf{F} = q \mathbf{v} \times \mathbf{B}$$
    - 安培力：$$d\mathbf{F} = I d\mathbf{l} \times \mathbf{B}$$

## 二、 常见基本模型与磁场分布

| 模型          | 示意图特征                                     | 磁感应强度 \(B\) 的大小                                             | 方向（右手定则）   |
| :---------- | :---------------------------------------- | :---------------------------------------------------------- | :--------- |
| **无限长直导线**  | 电流 \(I\) 沿直线                              | $$B = \frac{\mu_0 I}{2\pi r}$$                              | 环绕导线的同心圆   |
| **有限长直导线**  | 电流 $I$，长度 $L$，端点垂足夹角 $\theta_1, \theta_2$ | $$B = \frac{\mu_0 I}{4\pi r}(\sin\theta_1 + \sin\theta_2)$$ | 同上         |
| **圆形电流环轴线** | 半径 \(R\)，电流 \(I\)，轴线上距离圆心 \(x\)           | $$B = \frac{\mu_0 I R^2}{2(R^2 + x^2)^{3/2}}$$              | 沿轴线，右手螺旋   |
| **圆心处**     | \(x=0\)                                   | $$B = \frac{\mu_0 I}{2R}$$                                  | 垂直环面，右手螺旋  |
| **无限长直螺线管** | 单位长度匝数 \(n\)，电流 \(I\)                     | 内部：$$B = \mu_0 n I$$<br>外部：\(B \approx 0\)                  | 沿轴线，均匀     |
| **环形螺线管**   | 总匝数 \(N\)，平均半径 \(R\)                      | 内部：$$B = \frac{\mu_0 N I}{2\pi r}$$<br>（\(r\) 为环心到场点距离）     | 沿切向，右手螺旋   |
| **无限大载流平面** | 面电流密度 \($j_s$\) (A/m)                     | $$B = \frac{\mu_0 j_s}{2}$$                                 | 平行于平面，两侧反向 |
|             |                                           |                                                             |            |

## 三、 两种定律的适用场景对比

-   **毕奥-萨伐尔定律**：  
    - ✅ 适用：任何形状的载流导线（有限长、弯曲、任意形状）。  
    - ❌ 缺点：计算复杂，通常需矢量积分。
-   **安培环路定律**：  
    - ✅ 适用：无限长直导线、无限长螺线管、环形螺线管、无限大平面等高度对称模型。  
    - ❌ 限制：要求稳恒电流且对称性极高，否则无法直接求出 \(B\)。

## 四、 重要注意事项

1.  **稳恒电流前提**：原始安培环路定律仅适用于稳恒电流。非稳恒情况（如电容器充电）必须引入 **位移电流** 修正，使用安培-麦克斯韦定律。
2.  **曲面选择无关性**：稳恒电流下，对同一闭合回路，任意以该回路为边界的曲面所包围的净电流 \(I_{\text{enc}}\) 均相同。
3.  **记忆技巧**：  
    - 毕奥-萨伐尔定律 对应电场中的 库仑定律。  
    - 安培环路定律 对应电场中的 高斯定理。  
    - 洛伦兹力是微观形式，安培力是宏观表现。
