# 物理实验报告：测量螺线管的磁场

## 1. 实验目的
学习测量交变电场的方法，加深对磁场特性与电磁感应定律的理解
## 2.实验仪器
螺线管套件，数字示波器，低频信号发生器，电阻，导线
## 3.实验原理

### 实验原理

### 3.1 螺线管的磁场分布

#### 3.1.1 理想螺线管轴线上磁场公式

对于长度为 $L$、总匝数为 $N$、通有电流 $I$ 的密绕螺线管，其轴线上任意一点 $P$ 的磁感应强度为：

$$
B = \frac{\mu_0 n I}{2} (\cos \theta_1 - \cos \theta_2)
$$

其中：
- $\mu_0 = 4\pi \times 10^{-7} \, \text{N/A}^2$ —— 真空磁导率
- $n = N/L$ —— 单位长度匝数
- $\theta_1$、$\theta_2$ —— 从 $P$ 点看向螺线管两端时，与轴线的夹角

本实验中，使用长度为$2L$,匝数为$N$的单层密绕直螺线管，当导线中通过电流$I$时，取螺线管中点处为坐标原点，轴线为$X$轴，那么在轴线上某一点P处的磁感应强度为

$$
B(x) = \frac{\mu_0 n I}{2} \left( \frac{x + L/2}{\sqrt{(x + L/2)^2 + R^2}} - \frac{x - L/2}{\sqrt{(x - L/2)^2 + R^2}} \right)
$$

#### 3.1.2 特殊位置磁场

**（1）无限长螺线管内部**：$B = \mu_0 n I$，磁场均匀分布。

**（2）有限长螺线管中心点**：

$$
B_{\text{中心}} = \mu_0 n I \cos \alpha = \frac{\mu_0 N I}{\sqrt{L^2 + D^2}}
$$

其中 $D$ 为螺线管直径。

**（3）有限长螺线管端点**：

$$
B_{\text{端点}} = \frac{1}{2} \mu_0 n I \cos \beta \approx \frac{1}{2} B_{\text{中心}} \quad (\text{当 } L \gg D)
$$

---

### 3.2 交变磁场下的感应电动势

本实验采用**交变电流法**：螺线管（大线圈）通以低频交变电流 $i(t)=I_0 sin \omega t$，产生交变磁场 $B(t)$。将探测线圈（小线圈）置于磁场中，穿过探测线圈的磁通量发生变化，可得磁感应强度有效值：

$$
B = \frac{\varepsilon_{\text{rms}}}{2 \pi^2 N r^2 f}
$$

实验中，测量探测线圈的感应电动势有效值 $\varepsilon_{\text{rms}}$，已知频率 $f$、探测线圈匝数 $N$ 和 探测线圈半径$r$，即可计算 $B$。

---
### 3.3 电压表改装电流表
实验中使用示波器用于测量两端口间到电压，为了得到电路中的电流大小，可以用电压表与电阻并联，若电压表为理想电压表，则有
$$
I = \frac{V}{R}
$$
式中$I$为电路中电流大小，$V$为电压表示数，$R$为电阻阻值，当$R=1 \ohm$时，
$V = I$。
 
## 4.实验内容

### 4.1 测量螺线管中心磁场与电流$I$和感生电动势$\varepsilon_{\text{rms}}$的关系

1. 记录参数：螺线管的半径R，长度2L，总匝数N，探测线圈的半径r1,总匝数N1
2. 将探测线圈置于螺线管中心位置，即取$x=0$。
3. 通过选取低频信号发生器的频率为$f=4000Hz, 2000Hz, 1000Hz$, 调节信号输出使输出电流从$10.0mA$到$40.0mA$，每隔$5.0mA$记录对应的感应电动势有效值 $\varepsilon_{\text{rms}}$
4. 再取$x=l$，频率和电流取三组数值$(4000Hz, 10.0mA), (2000Hz, 20.0mA), (1000Hz, 40.0mA)$，测量出对应的感生电动势$\varepsilon_{\text{rms}}$，分别用两个公式算出B，再与测量结果进行比较和讨论。

### 4.2 测量螺线管轴线磁场分布

1. 固定$f=2000Hz, I=20.0mA$。当$x=0$时记录下此时的感生电动势$\varepsilon_{\text{rms}}$
2. 沿轴线向外移动探测线圈，每隔1.0cm记录位置 $x$ 对应的感应电动势有效值 $\varepsilon_{\text{rms}}$直到21.0cm
3. 由于 $\varepsilon_{\text{rms}} \propto B$，可绘制 $\varepsilon_{\text{rms}} \sim x$ 曲线，反映磁场分布。

### 计算结果

| 位置 | 有限长螺线管公式 $B_1$ (mT) | 感应电动势公式 $B_2$ (mT) | 相对偏差 |
| :---: | :---: | :---: | :---: |
| 中心 ($x=0$) | 0.3240 | 0.3441 | $+6.2\%$ |
| 端点 ($x=L$) | 0.1624 | 0.1497 | $-7.8\%$ |

**公式说明**：
- $B_1 = \dfrac{\mu_0 N_{\text{sol}} I}{\sqrt{L^2 + D^2}}$（中心），$B_1 = \dfrac{\mu_0 N_{\text{sol}} I}{2\sqrt{L^2 + R^2}}$（端点）
- $B_2 = \dfrac{\varepsilon_{\text{rms}}}{2\pi^2 N r^2 f}$

**理论比值**（端点/中心）：$B_{1,\text{端点}} / B_{1,\text{中心}} = 0.501$  
**实验比值**（$B_2$）：$0.1497 / 0.3441 = 0.435$

---

### 结论
- 两种方法测得的磁场在中心处偏差 $6.2\%$，端点处偏差 $-7.8\%$，可能源于线圈参数误差、位置对准偏差及公式系数简化。
- 端点磁场实测值约为中心的 $43.5\%$，与理论预期 $50\%$ 存在一定差距，提示测量系统存在系统误差。

### 6.5 螺线管轴线磁场分布数据结果

#### 1. 实验曲线特征

- **中心平坦区**：在 $x = 0$ 至 $x \approx 10\,\text{cm}$ 范围内，测量电压稳定在 $334.4 \sim 334.6\,\text{mV}$ 之间，波动小于 $0.1\%$，表明螺线管内部磁场十分均匀。
- **端部衰减**：当 $x > 10\,\text{cm}$ 后，磁场开始缓慢下降；至端点 $x = 18.0\,\text{cm}$ 处，电压降至 $147.1\,\text{mV}$，约为中心值的 $44.0\%$（理论预期为 $50\%$，偏差源于线圈非理想绕制或测量位置偏差）。
- **外部迅速衰减**：超出端点后，磁场急剧减小，$x = 21\,\text{cm}$ 处电压仅剩 $11.0\,\text{mV}$，趋近于零。

#### 2. 实验与理论对比

- 将有限长螺线管理论公式 $B(x)$ 按中心点实验值缩放后，得到的理论曲线（图红色虚线）与实验数据（蓝色实线）**整体趋势高度一致**。
- 在 $x = 5 \sim 15\,\text{cm}$ 区间，理论曲线略低于实验值，最大相对偏差约 $3\%$；在端点外部，两者几乎重合。
- 轻微偏差可能来源于：
  - 螺线管实际长度/半径与标称值的微小差异；
  - 探测线圈平面未严格垂直轴线，导致感应电动势略小于理论最大值；
  - 测量点位置读数误差（如 $x=0$ 未必是绝对中心）。

#### 3. 主要结论

- 实验成功验证了有限长螺线管轴线磁场的理论分布公式。
- 磁场在螺线管内部均匀，在端点处约下降为中心的一半，外部指数衰减。
- 该方法（交变电流法 + 探测线圈）可准确、直观地测量交变磁场的空间分布，适用于磁路分析与教学演示。

## 7. 实验结论

1. 螺线管中心磁感应强度 $B_{\text{中心}}$ 与励磁电流 $I$ 呈良好的线性关系，验证了 $B = \mu_0 n I$ 的理论公式。
2. 轴线磁场分布与理论公式 $B = \dfrac{\mu_0 n I}{2}(\cos \theta_1 - \cos \theta_2)$ 基本吻合，中心处磁场最强，端点处约为中心处的一半。

## 8. 误差分析

### 8.1 主要误差来源

| 误差类型 | 来源 | 说明 |
| :--- | :--- | :--- |
| 系统误差 | 螺线管非理想 | 实际螺线管绕制不均匀，存在端部效应 |
| 系统误差 | 探测线圈尺寸 | 线圈有一定大小，测量的是平均磁场而非点磁场 |
| 系统误差 | 线圈未严格垂直 | 探测线圈平面与轴线不垂直，感应电动势偏小 |
| 系统误差 | 仪器精度 | 电压表、信号发生器的固有误差 |
| 随机误差 | 位置读数 | 探测线圈位置读取存在估读误差 |
| 随机误差 | 外界干扰 | 工频（50Hz）及其他电磁干扰 |

### 8.2 减小误差的方法

1. 确保探测线圈平面与螺线管轴线垂直，获得最大感应电动势
2. 测量时缓慢移动探测线圈，避免位置偏差
3. 多次测量取平均值，减小随机误差
4. 实验中远离电磁干扰源（如变压器、电机等）
5. 使用屏蔽线连接探测线圈与电压表，减少外界干扰

## 9. 思考题

### 9.1 实验中为什么将探测线圈置于螺线管中心测量 $B \sim I$ 关系？

**答**：螺线管中心处的磁场最均匀（端部效应影响最小），且理论公式最简单（$B = \mu_0 n I$）。在中心处测量 $B \sim I$ 关系，线性度最好，便于验证比例关系，同时可避免端部磁场不均匀带来的额外误差。

---

### 9.2 若探测线圈平面与螺线管轴线不垂直，对测量结果有何影响？

**答**：设夹角为 $\theta$，则穿过探测线圈的有效磁通量为 $\Phi = N_s B S \cos \theta$，感应电动势与 $\cos \theta$ 成正比。当 $\theta \neq 0$ 时，测量值偏小，导致计算出的磁场 $B_m$ 也偏小。实验中应调整线圈使 $\theta = 0$（即感应电动势最大），确保测量准确。

---

### 9.3 螺线管外部的磁场分布有何特点？实验中是否测量了外部磁场？

**答**：螺线管外部磁场很弱，且随距离增大迅速衰减。理论上，对于有限长螺线管，外部磁场不为零，但远小于内部磁场。若实验条件允许，可测量外部磁场验证这一特性。
