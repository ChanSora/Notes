# 实验报告：线性与非线性元件的伏安特性曲线测量

## 1. 实验目的

- 掌握线性与非线性元件的伏安特性测量方法。
- 理解制流电路和分压电路的工作原理，学习恒压源和恒流源的使用。
- 测量普通电阻、钨丝小灯泡、发光二极管（LED）、稳压二极管的伏安特性曲线。
- 分析不同元件的伏安特性差异，理解其工作原理。

## 2. 实验原理

### 2.1 伏安特性
元件的伏安特性是指通过元件的电流 $I$ 与两端电压 $U$ 之间的关系。若 $I$ 与 $U$ 成正比，则称为线性元件（如普通电阻）；否则为非线性元件。

### 2.2 钨丝小灯泡
小灯泡的钨丝具有正温度系数。当电流增大、温度升高时，电阻增大，因此其 $I-U$ 曲线呈非线性，斜率逐渐减小。

### 2.3 发光二极管（LED）
LED 是一种具有单向导电性的非线性元件。当正向电压达到导通电压（约 1.5–3V）后，电流随电压指数增长，同时发光。

### 2.4 稳压二极管
稳压二极管在正向偏置时与普通二极管类似；在反向偏置且电压达到击穿电压（稳压值）后，电流急剧增大而电压几乎不变，从而实现稳压功能。

### 2.5 恒压源和恒流源

#### 2.5.1 恒压源

**定义**：输出电压保持恒定的电源，不随负载电流变化。

**理想特性**：$U = U_0$（恒定），内阻 $r = 0$。

**实际特性**：$U = U_0 - I \cdot r$，内阻 $r$ 越小，恒压性能越好。

**伏安特性曲线**：垂直于电压轴的直线。

---

#### 2.5.2 恒流源

**定义**：输出电流保持恒定的电源，不随负载电阻变化。

**理想特性**：$I = I_0$（恒定），内阻 $r = \infty$。

**实际特性**：$I = I_0 - U / r$，内阻 $r$ 越大，恒流性能越好。

**伏安特性曲线**：垂直于电流轴的直线。

---

#### 三、对比总结

| 特性    | 恒压源           | 恒流源         |
| :---- | :------------ | :---------- |
| 输出量   | 电压恒定          | 电流恒定        |
| 理想内阻  | $0$           | $\infty$    |
| 伏安曲线  | 竖直线           | 水平线         |
| 本实验应用 | 测量元件两端电压随电流变化 | 直接控制通过元件的电流 |

## 3. 实验设备

- 恒流电源，恒压电源
- 数字万用表（电压、电流测量）
- 待测元件：钨丝小灯泡、蓝色和绿色发光二极管、稳压二极管
- 导线若干

## 4.实验内容

### 4.1. 测量钨丝小灯泡的伏安特性曲线

#### 4.1.1 实验步骤

1. 按**电流表内接法**连接电路（稳压电源 → 电流表 → 小灯泡 → 电压表并联在小灯泡两端）。
2. 调节稳压电源输出电压，从 $0.000 \, \text{V}$ 开始，每隔 $0.500 \, \text{V}$ 记录一次电流表示数，直至 $7.000 \, \text{V}$。
3. 将电路改为**电流表外接法**（稳压电源 → 小灯泡 → 电流表串联在干路，电压表并联在小灯泡两端）。
4. 重复步骤 2，记录对应电压下的电流值。
5. 在同一坐标系中绘制两条 $I-U$ 曲线，比较差异并分析原因。
### 4.2. 测量发光二极管（LED）的伏安特性曲线

#### 4.2.1 实验步骤

1. 按**电流表外接法**连接电路（恒流源 → LED → 电流表串联，电压表并联在 LED 两端）。
2. 将恒流源输出电流从 $0 \, \text{mA}$ 开始逐渐增大，每隔 $2 \, \text{mA}$ 记录一次电压表示数，直至 $20 \, \text{mA}$。
3. 分别测量**绿色 LED** 和**蓝色 LED** 的正向伏安特性数据。
4. 在同一坐标系中绘制两种 LED 的 $I-U$ 曲线。
5. 从曲线上读取阈值电压 $U_D$（电流开始显著增加时的电压，通常取 $I = 1 \, \text{mA}$ 或曲线拐点处）。
6. 根据公式 $\lambda = 1240 / U_D$（$\lambda$ 单位 nm，$U_D$ 单位 V）计算两种 LED 的发光波长。

---

### 4.3. 测量稳压二极管的伏安特性曲线

#### 4.3.1 实验步骤

**正向特性测量**：

1. 按正向偏置连接电路（稳压电源 → 限流电阻 → 稳压二极管（正极接高电位）→ 电流表串联，电压表并联在二极管两端）。
2. 逐渐增大电源电压，记录正向电压 $U$ 及对应的正向电流 $I$（确保 $I \leq 50 \, \text{mA}$）。
3. 记录 $10$ 个以上数据点，覆盖从截止到导通的完整过程。

**反向特性测量**：

1. 将稳压二极管反向连接（负极接高电位，正极接低电位），串联限流电阻。
2. 逐渐增大反向电压，记录反向电压 $U$ 及对应的反向电流 $I$。
3. 注意反向电流单位：击穿前为 μA 级，击穿后变为 mA 级。
4. 击穿后电流急剧增大，应缓慢调节电压，防止电流超过 $50 \, \text{mA}$ 损坏二极管。
5. 记录稳压二极管的反向击穿电压（稳压值）$U_Z$。

## 6. 数据分析

![](./伏安特性曲线.png)

### 6.1. 钨丝小灯泡伏安特性分析

#### 6.1.1 曲线特征

实验数据表明，小灯泡的 $I-U$ 曲线呈**非线性**，斜率随电压升高而**减小**，说明电阻随电压升高而**增大**（$R = U/I$ 从约 $17.7\,\Omega$ 增至 $70.7\,\Omega$）。

#### 6.1.2 物理原因

钨丝具有**正温度系数**：$R = R_0(1 + \alpha \cdot \Delta T)$。电压升高 → 电流增大 → 焦耳热增加 → 温度升高 → 电阻增大 → 电流增速减慢。

#### 6.1.3 内外接法误差分析

| 方法 | 测量值 | 误差来源 | 相对误差 | 本实验表现 |
| :--- | :--- | :--- | :--- | :--- |
| 内接法 | $U$ 偏大 | 电流表分压 | $R_A/R_x$ | 曲线向右偏移 |
| 外接法 | $I$ 偏大 | 电压表分流 | $R_x/R_V$ | 曲线向上偏移 |

小灯泡冷态电阻小（≈ $18\,\Omega$），内接法分压显著；热态电阻增大（≈ $70\,\Omega$），两种方法差异随电压升高而缩小。电压表内阻（≈ $1\,\text{M}\Omega$）远大于灯泡电阻，外接法更准确。

---

### 6.2. LED 伏安特性分析

#### 6.2.1 曲线特征

LED 的 $I-U$ 曲线呈**指数增长**形：存在阈值电压 $U_D$，超过后电流迅速上升。

| LED | $U_D$ (V) | 特征 |
| :--- | :---: | :--- |
| 绿色 | 2.36 | 导通后电压缓慢上升至 3.43 V（@50mA） |
| 蓝色 | 2.81 | 导通后电压缓慢上升至 3.83 V（@50mA） |

#### 6.2.2 物理原因

LED 的 PN 结满足 $I = I_S(e^{U/nU_T} - 1)$，呈指数伏安特性。蓝色 LED 阈值电压更高，因其禁带宽度更大。

#### 6.2.3 阈值电压与发光波长关系

由 $eU_D = hc/\lambda$ 得简化公式：

$$
\lambda (\text{nm}) = \frac{1240}{U_D (\text{V})}
$$

| LED | $U_D$ (V) | 计算 $\lambda$ (nm) | 理论范围 (nm) |
| :--- | :---: | :---: | :---: |
| 绿色 | 2.36 | 525 | 495–570 |
| 蓝色 | 2.81 | 441 | 450–495 |

计算结果与理论范围基本吻合，验证了公式的正确性。阈值电压越高，波长越短（蓝移）。

---

### 6.3. 稳压二极管伏安特性分析

#### 6.3.1 正向特性

正向特性与普通二极管类似：导通电压约 $0.72\,\text{V}$，导通后电压随电流增加缓慢上升（$0.72 \to 0.84\,\text{V}$），动态电阻很小。

#### 6.3.2 反向特性

| 区域 | 电压范围 | 特征 |
| :--- | :--- | :--- |
| 截止区 | $< 3.08\,\text{V}$ | 电流极小（μA级） |
| 击穿区 | $\approx 3.1\,\text{V}$ | 击穿起始点 |
| 稳压区 | $3.1 \to 4.0\,\text{V}$ | 电流 $4 \to 50\,\text{mA}$，电压变化仅 $0.9\,\text{V}$ |

动态电阻 $r_Z = \Delta U/\Delta I \approx 19.8\,\Omega$，稳压性能良好。击穿后电压被钳位，实现稳压功能。

---

### 6.4. 元件对比总结

| 元件 | 非线性原因 | $I-U$ 特征 |
| :--- | :--- | :--- |
| 小灯泡 | 正温度系数 | 斜率随 $U$ 增大而减小 |
| LED | PN 结指数特性 | 存在阈值电压，指数上升 |
| 稳压二极管（正向） | PN 结导通 | 与普通二极管相同 |
| 稳压二极管（反向） | 齐纳/雪崩击穿 | 击穿后电压恒定 |

## 7. 误差分析

### 7.1 主要误差来源

| 误差类型 | 来源 | 说明 |
| :---: | :--- | :--- |
| 系统误差 | 电表内阻 | 电流表分压、电压表分流导致测量偏差 |
| 系统误差 | 仪表精度 | 万用表本身存在准确度等级（如 ±0.5%） |
| 系统误差 | 接触电阻 | 导线与元件接触点存在附加电阻 |
| 随机误差 | 读数误差 | 指针或数字跳动，估读不准确 |
| 随机误差 | 温度变化 | 小灯泡灯丝温度受环境及通电时间影响 |
| 方法误差 | 阈值电压取值 | LED 阈值电压的读取位置存在主观性 |

### 7.2 内外接法误差定量分析

**内接法相对误差**：$\delta_{\text{内}} = R_A / R_x$

**外接法相对误差**：$\delta_{\text{外}} = R_x / R_V$

小灯泡冷态电阻约 $18\,\Omega$，热态电阻约 $70\,\Omega$；电流表内阻约 $0.5\,\Omega$，电压表内阻约 $1\,\text{M}\Omega$。

| 状态 | 内接法误差 | 外接法误差 | 较优方法 |
| :--- | :---: | :---: | :---: |
| 冷态（$R_x \approx 18\,\Omega$） | $\approx 2.8\%$ | $\approx 0.002\%$ | 外接法 |
| 热态（$R_x \approx 70\,\Omega$） | $\approx 0.7\%$ | $\approx 0.007\%$ | 外接法 |

**结论**：外接法误差始终小于内接法，是小灯泡测量的较优选择。

### 7.3 LED 波长计算误差

| LED | $U_D$ (V) | 计算 $\lambda$ (nm) | 理论 $\lambda$ (nm) | 相对误差 |
| :---: | :---: | :---: | :---: | :---: |
| 绿色 | 2.36 | 525 | 495–570 | 在范围内 |
| 蓝色 | 2.81 | 441 | 450–495 | $\approx 2\%$ |

误差可能原因：
- 阈值电压取 $I = 1\,\text{mA}$ 处的电压，实际导通点略有差异
- 公式 $eU_D = hc/\lambda$ 为理想近似，未考虑材料缺陷、温度等因素
- 万用表读数存在系统误差

### 7.4 减小误差的方法

1. 测量小灯泡时优先采用**外接法**
2. 每次测量前等待示数稳定，避免灯丝温度变化
3. 多次测量取平均值
4. 使用高精度数字万用表
5. 保持环境温度恒定，减少导线接触电阻

## 8. 思考题

### 8.1 为什么小灯泡的伏安特性曲线不是一条直线？

**答**：小灯泡灯丝由金属钨制成，具有**正温度系数**。当电压升高、电流增大时，焦耳热使灯丝温度升高，电阻随之增大，因此 $I-U$ 曲线的斜率 $dI/dU$ 逐渐减小，呈现非线性。

### 8.2 内接法和外接法在什么条件下误差最小？

**答**：
- 内接法适用于测量**大电阻**（$R_x \gg R_A$），此时电流表分压可忽略
- 外接法适用于测量**小电阻**（$R_x \ll R_V$），此时电压表分流可忽略

本实验中小灯泡电阻较小，应选用**外接法**。

### 8.3 LED 的阈值电压与发光颜色有什么关系？

**答**：阈值电压 $U_D$ 与发光波长 $\lambda$ 成**反比**：$U_D \propto 1/\lambda$。阈值电压越高，波长越短（蓝移）；阈值电压越低，波长越长（红移）。这是因为 $U_D$ 反映了 PN 结的禁带宽度，禁带宽度越大，复合释放的光子能量越高，波长越短。

### 8.4 稳压二极管为什么能够稳压？

**答**：当反向电压达到击穿电压后，PN 结发生**齐纳击穿**或**雪崩击穿**，载流子数量急剧增加，电流迅速增大，但两端电压被钳位在击穿电压附近（变化很小）。这一特性使稳压二极管在反向击穿区可作为稳压元件使用。

### 8.5 实验中如何防止二极管烧坏？

**答**：
- 串联限流电阻，限制最大电流
- 测量时电流从零逐渐增大，避免突变
- 确保正向电流不超过 $50\,\text{mA}$
- 测量稳压二极管反向特性时尤其注意，击穿后电流急剧增大

## 9. 实验结论

### 9.1 实验结果总结

| 元件 | 伏安特性 | 关键参数 |
| :--- | :--- | :--- |
| 钨丝小灯泡 | 非线性，斜率随电压增大而减小 | 电阻 $18 \to 70\,\Omega$ |
| 绿色 LED | 指数型，存在阈值电压 | $U_D = 2.36\,\text{V}$，$\lambda \approx 525\,\text{nm}$ |
| 蓝色 LED | 指数型，存在阈值电压 | $U_D = 2.81\,\text{V}$，$\lambda \approx 441\,\text{nm}$ |
| 稳压二极管（正向） | 与普通二极管相同 | 导通电压约 $0.72\,\text{V}$ |
| 稳压二极管（反向） | 击穿后电压恒定 | 稳压值约 $3.1\,\text{V}$，$r_Z \approx 19.8\,\Omega$ |

### 9.2 主要结论

1. **小灯泡**的伏安特性反映了金属导体的电阻温度效应，电阻随温度升高而增大。
2. **内外接法**中，外接法更适用于小电阻测量，误差更小。
3. **LED** 的伏安特性符合 PN 结指数模型，阈值电压与发光波长满足 $\lambda = 1240/U_D$，实验值与理论吻合。
4. **稳压二极管**正向与普通二极管相同，反向击穿后具有稳压特性，动态电阻小。
5. 线性元件（定值电阻）的 $I-U$ 曲线为直线；本实验中所有被测元件均为非线性元件，但其非线性机制各不相同。
