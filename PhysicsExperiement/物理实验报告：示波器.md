# 物理实验报告：示波器

## 1. 实验目的
- 了解示波器的基本结构和原理

- 学习使用示波器观察波形和测量信号周期及时间参数等
## 2. 实验原理
### 2.1 示波器原理
#### 2.1.1 示波器概述
示波器（Oscilloscope）是一种能够直观显示电压信号随时间变化的电子测量仪器。它将电信号转换为可视化的波形图，纵轴表示电压幅度，横轴表示时间。

---
#### 2.1.2 示波器的基本组成

示波器主要由以下五个核心部分组成：

| 组成部分             | 功能描述              |
| :--------------- | :---------------- |
| 阴极射线管（CRT）或液晶显示屏 | 显示波形              |
| 垂直偏转系统（Y轴）       | 控制电子束的垂直运动，反映信号电压 |
| 水平偏转系统（X轴）       | 控制电子束的水平运动，反映时间   |
| 同步触发系统           | 使波形稳定显示           |
| 电源系统             | 提供各电路所需电压         |

### 2.2 阴极射线管（CRT）工作原理

CRT是传统模拟示波器的核心显示器件，其工作原理如下：

#### 2.2.1 电子枪

电子枪由灯丝、阴极、栅极、第一阳极和第二阳极组成：
- **灯丝**：加热阴极
- **阴极**：受热发射电子
- **栅极**：控制电子束强度（即波形亮度）
- **阳极**：加速并聚焦电子束

#### 2.2.2 偏转系统

- **垂直偏转板（Y偏转板）**：加被测电压，使电子束上下偏转
- **水平偏转板（X偏转板）**：加锯齿波扫描电压，使电子束左右匀速扫描
![](/figures/image2-31.png)
#### 2.2.3 荧光屏
电子束轰击荧光屏上的荧光物质，发出可见光，形成波形轨迹
### 2.3 基本工作流程

1. **输入信号**：被测信号通过探头接入示波器
2. **垂直放大**：信号经垂直衰减/放大电路处理后送至垂直偏转板
3. **时基扫描**：时基电路产生线性锯齿波电压，送至水平偏转板
4. **电子束偏转**：电子束同时受垂直信号和水平扫描电压的作用，在荧光屏上扫描出信号波形
5. **同步触发**：触发电路确保每次扫描起点相同，使波形稳定显示

### 2.4 波形显示原理

设垂直方向输入正弦电压 $U_y = U_m \sin(\omega t)$，水平方向输入锯齿波电压 $U_x = kt$。电子束在荧光屏上的位置由两者共同决定：

- 水平方向：$x \propto U_x \propto t$
- 垂直方向：$y \propto U_y \propto \sin(\omega t)$

因此，荧光屏上将显示出 $y \propto \sin(\omega x)$ 的正弦波形。

### 2.5 同步触发原理

#### 2.5.1 为什么需要同步？

如果扫描起点与被测信号不相关，每次扫描显示的波形起点不同，荧光屏上将出现**漂移的、不稳定的**波形。
#### 2.5.2 触发工作方式

触发系统从被测信号中提取触发信号，控制锯齿波发生器，确保每次扫描起点都对应被测信号的同一相位点。

常见触发方式：
- **内触发**：取自被测信号本身
- **外触发**：取自外部信号源
- **电源触发**：取自交流电源（50Hz）
#### 2.5.3 触发条件

- **触发电平**：信号达到预设电压值时触发
- **触发斜率**：上升沿触发或下降沿触发

### 2.6 李萨如图形原理

当示波器工作在 **X-Y 模式**时，两个通道分别输入不同信号：

- X 通道：$U_x = A \sin(\omega_x t + \varphi_x)$
- Y 通道：$U_y = B \sin(\omega_y t + \varphi_y)$

电子束在荧光屏上合成运动的轨迹称为**李萨如图形（Lissajous Figure）**。

#### 2.6.1 频率比与图形的关系

当 $\omega_x : \omega_y$ 为有理数比时，图形稳定。频率比决定了图形的切点数：

$$
\frac{f_y}{f_x} = \frac{\text{水平方向切点数}}{\text{垂直方向切点数}}
$$

| 频率比 $f_y : f_x$ | 相位差 $\Delta \varphi$ | 李萨如图形 |
| :-------------: | :------------------: | :---: |
|       1:1       |          0           | 直线（/） |
|       1:1       |       $\pi/2$        |  正圆   |
|       1:1       |        $\pi$         | 直线（\） |
|       2:1       |          —           |  8字形  |

![常见李萨如图形](figures/image4-68.png)
![常见李萨如图形2](figures/image5-70.png)
*常见李萨如图形（不同频率比和相位差）*

#### 2.6.2 测量频率

通过李萨如图形可以测量未知信号的频率：

1. 将已知频率信号 $f_x$ 接入 X 通道
2. 将未知频率信号 $f_y$ 接入 Y 通道
3. 调节 $f_x$ 使图形稳定
4. 根据图形切点数计算：

$$
f_y = \frac{\text{水平切点数}}{\text{垂直切点数}} \times f_x
$$

## 4.实验内容

---
### 4.1 示波器自带信号测试

1. 将示波器探头连接至通道 CH1（或 CH2）。
2. 将探头尖端接至示波器自带的**校准信号输出端**（ $1\,\text{kHz}$、$V_{pp} = 2\,\text{V}$ 的方波信号）。
3. 调节示波器的**垂直刻度（VOLTS/DIV）** 和 **水平刻度（TIME/DIV）**，使波形在屏幕上完整显示（约 2-3 个周期）。
4. 调节**垂直位置**和**水平位置**旋钮，将波形调整至屏幕中央。
5. 调节**触发电平（TRIGGER LEVEL）**，使波形稳定显示。
6. 读取波形的垂直幅度（格数）和水平周期（格数），记录数据。
7. 再将信号发生器一通道与示波器CH1通道相连，将信号发生器一通道的输出调整为与校准信号相同。
8. 重复之前的操作，记录数据。

### 4.2 相位差与李萨如图形的关系

1. 将信号发生器的两个输出端接入示波器的 **CH1（X 通道）** 和 **CH2（Y 通道）**。
2. 设置信号发生器输出：**正弦波**，$f = 1\,\text{kHz}$，$V_{pp} = 3\,\text{V}$。
3. 示波器设置为 **X-Y 模式**
4. 观察屏幕上显示的**直线**（斜率为正）图形。
5. 在 CH2 通道的信号源上调整信号的相位。
6. 缓慢调节移相量，观察图形变化：
   - 直线（/）→ 椭圆 → 正圆 → 椭圆 → 直线（\）→ 椭圆 → 正圆 → 椭圆 → 直线（/）
7. 记录不同相位差对应的图形形状。

### 4.3 不同频率之比与李萨如图形的关系

1. 将示波器设置为 **X-Y 模式**。
2. CH1（X 通道）接入信号发生器的第一路输出：正弦波，$f_x = 1.2\,\text{kHz}$，$V_{pp} = 3\,\text{V}$。
3. CH2（Y 通道）接入信号发生器的第二路输出：正弦波，$V_{pp} = 3\,\text{V}$。
4. 依次调节 $f_y$ 为以下频率，观察并记录李萨如图形：
   - $f_y = 0.6\,\text{kHz}$（$f_y : f_x = 1:2$）
   - $f_y = 0.4\,\text{kHz}$（$f_y : f_x = 1:3$）
   - $f_y = 0.8\,\text{kHz}$（$f_y : f_x = 2:3$）
   - $f_y = 0.9\,\text{kHz}$（$f_y : f_x = 3:4$）
5. 对于每个频率比，根据图形切点数验证频率比公式。

## 6. 误差分析
---
### 6.1 主要误差来源

| 误差类型 | 来源      | 说明                                    |
| :--- | :------ | :------------------------------------ |
| 系统误差 | 示波器刻度精度 | VOLTS/DIV 和 TIME/DIV 刻度本身存在 ±3% 左右的误差 |
| 系统误差 | 探头衰减比   | 探头衰减倍数（×1 / ×10）可能存在偏差                |
| 系统误差 | 信号发生器频率 | 输出频率存在微小漂移                            |
| 随机误差 | 读数估读    | 格数读取时无法完全对齐刻度线                        |
| 随机误差 | 波形判断    | 李萨如图形切点数、直线方向的判断存在主观性                 |
| 随机误差 | 相位调节    | 移相器调节难以精确达到预设相位值                      |

---
### 6.2 减小误差的方法

1. **多次测量取平均**：每个数据点测量 3-5 次，取平均值
2. **校准仪器**：测量前用示波器自带校准信号校正探头
3. **波形居中**：将波形调至屏幕中央刻度线处读数，减小视差
4. **适当放大**：调节 VOLTS/DIV 和 TIME/DIV 使波形幅度适中（占屏幕 4-6 格），提高读数精度
5. **稳定波形**：仔细调节触发电平，确保波形完全稳定后再读数

## 7. 思考题

---
### 7.1. 当两个信号频率相同、相位差为 0 时，李萨如图形为什么是直线？请从运动合成角度解释。

**答**：设两个信号的表达式为：

$$
x = A \sin(\omega t), \quad y = B \sin(\omega t)
$$

消去参数 $t$，得：

$$
\frac{y}{x} = \frac{B}{A} \quad \Rightarrow \quad y = \frac{B}{A} \cdot x
$$

这是一个正比例函数，表示电子束在 X、Y 方向**同步运动**，任意时刻两者的位移比值恒定，因此合成轨迹为一条通过原点的**直线**，斜率为 $B/A$。

---

### 7.2. 若 X-Y 模式下观察到的是椭圆而不是直线，如何判断当前相位差是 $\pi/2$ 还是 $3\pi/2$？

**答**：可以通过观察椭圆的**旋转方向**来判断：

- 将示波器 X-Y 模式下的**扫描时间**调大（或观察时，想象电子束的运动轨迹）
- 更常用的方法：**在 CH1 或 CH2 上加入一个小的时间延迟（或直接观察实际波形相位关系）**
- 或者，将示波器切换回 **时间模式**，直接比较两个通道的波形，看 Y 波形相对于 X 波形是 **超前** 还是 **滞后**

具体规律：

| 相位差 | 图形 | 判断方法 |
| :---: | :---: | :--- |
| $\pi/2$（Y 超前 X） | 正椭圆 | 若 Y 超前 X，椭圆按顺时针或逆时针方向旋转（取决于示波器定义） |
| $3\pi/2$（Y 滞后 X） | 正椭圆 | 旋转方向相反 |

通常可通过**微调移相器**，观察椭圆变化趋势来辅助判断。

---

### 7.3. 为什么要求两个信号的频率比为有理数时李萨如图形才能稳定？频率比为无理数时会出现什么现象？

**答**：

- **有理数比时**：两个信号经过有限个周期后，运动状态**重复出现**，电子束的轨迹是闭合的周期曲线，图形稳定。
- **无理数比时**：两个信号的周期之比为无理数，永远不会同时回到初始相位，电子束的轨迹**永不闭合**，会逐渐铺满整个矩形区域，图形看起来**缓慢旋转且不断变化**，无法稳定观察。

---

### 7.4. 用李萨如图形法测量频率有哪些优点和局限性？

**答**：

| 项目 | 说明 |
| :--- | :--- |
| **优点** | 1. 直观、简单，无需复杂计算<br>2. 精度较高（与标准频率源精度相当）<br>3. 适合测量低频、超低频信号<br>4. 可同时观察频率比和相位关系 |
| **局限性** | 1. 需要已知频率的标准信号源<br>2. 要求两个信号波形均为正弦波，波形失真会影响图形判断<br>3. 频率比太大时，图形复杂，切点数难以准确数清<br>4. 无法直接测量非正弦波信号<br>5. 对于频率比不是简单整数比的信号，图形不稳定，测量困难 |
