# DigitalLogic
## §2 Boolean Algebra

- **Boolean algebra（逻辑代数）**，由 George Boole 于 1854 年提出，是一个演绎数学系统，研究逻辑运算所遵循的规则。
- Boolean algebra 是一个代数结构，由以下要素定义：
  - 一组元素 $S$：二值变量；
  - 一组二元运算符：AND（$\cdot$）、OR（$+$）和 NOT（$'$）；
  - 以及若干公理/定理。
- 公理和定理用于化简布尔方程。
- 公理和定理中的一个重要性质：**Duality（对偶性）**
  - 将 $\cdot$ 替换为 $+$，将 $0$ 替换为 $1$，等式关系仍然成立。

| 编号 | 定理 | 对偶形式 | 名称 |
| :---: | :---: | :---: | :---: |
| 1 | $x + 0 = x$ | $x \cdot 1 = x$ | Identity |
| 2 | $x + 1 = 1$ | $x \cdot 0 = 0$ | Null Element |
| 3 | $x + x = x$ | $x \cdot x = x$ | Idempotency |
| 4 | $(x')' = x$ | | Involution |
| 5 | $x + x' = 1$ | $x \cdot x' = 0$ | Complements |

- **运算符优先级**
  - 括号 > NOT > AND > OR

- **对偶（Dual）**：将 $\cdot$ 替换为 $+$，将 $0$ 替换为 $1$，等式关系保持不变。

| 编号 | 定理 | 对偶形式 | 名称 |
| :---: | :---: | :---: | :---: |
| 6 | $xy = yx$ | $x + y = y + x$ | Commutativity |
| 7 | $(xy)z = x(yz)$ | $(x + y) + z = x + (y + z)$ | Associativity |
| 8 | $x(y + z) = xy + xz$ | $x + yz = (x + y)(x + z)$ | Distributivity |
| 9 | $x + xy = x$ | $x(x + y) = x$ | Absorption |
| 10 | $xy + xy' = x$ | $(x + y)(x + y') = x$ | Combining |
| 11 | $(x+y')y = xy$ | $xy' + y = x + y$ | Simplification |
| 12 | $xy + x'z + yz = xy + x'z$ | $(x + y)(x' + z)(y + z) = (x + y)(x' + z)$ | Consensus |
| 13 | $(x + y)' = x'y'$ | $(xy)' = x' + y'$ | DeMorgan's law |

> **注意**：第 8 条的对偶形式与传统代数不同：OR（$+$）对 AND（$\cdot$）可分配。

## 布尔函数与逻辑图

- 一个代数表达式形式的布尔函数可以实现为由逻辑门组成的逻辑图。
  - 二值变量
  - 运算符 OR、AND、NOT
  - 括号

- **术语**：
  - **Literal（文字）**：一个变量或其反变量。
  - **Product term（乘积项）**：由 $\cdot$ 连接的文字。
  - **Sum term（和项）**：由 $+$ 连接的文字。

- **示例**：
  - $A'B'C + A'BC + AB'$ 有 8 个文字，3 个乘积项。
  - $(A+B'+C)(A'+C)$ 有 5 个文字，2 个和项。

## 布尔函数的补函数

- 任意函数 $F$ 的补函数为 $F'$，可通过 DeMorgan 定理求得：
  - 先取表达式的对偶形式，然后对 $F$ 中的每个文字取补。

- **示例**：$F_3 = x'y'z + x'yz + xy'$

  - **Step 1**：通过将 $\cdot$ 替换为 $+$、将 $0$ 替换为 $1$ 来求对偶形式：

  $$x'y'z + x'yz + xy' \xrightarrow{\text{Dual}} (x'+y'+z)(x'+y+z)(x+y')$$

  > **注意！** 对偶（dual）不是对偶性（duality）！转换尚未完成。
  > $$x'y'z + x'yz + xy' \neq (x'+y'+z)(x'+y+z)(x+y')$$

  - **Step 2**：对 $F$ 中的每个文字取补：

  $$F_3' = (x'y'z + x'yz + xy')'$$
  $$= (x+y+z')(x+y'+z')(x'+y) \quad \text{(DeMorgan)}$$

## Minterms 和 Maxterms

- **Minterm（最小项）**：一个 AND 项，由所有文字以其原变量形式或反变量形式组成。
  - 例如，两个二值变量 $x$ 和 $y$：
    - $x'y'$、$x'y$、$xy'$、$xy$（$m_0 \sim m_3$）
  - $n$ 个变量可以组合成 $2^n$ 个最小项。

- **Maxterm（最大项）**：一个 OR 项。
  - 例如，两个二值变量 $x$ 和 $y$：
    - $x+y$、$x+y'$、$x'+y$、$x'+y'$（$M_0 \sim M_3$）
  - 共 $2^n$ 个最大项。

### 真值表中的 Minterms 和 Maxterms

- **Minterms**
  - 每个最小项由 $n$ 个变量的 AND 项得到，若对应二进制位为 0 则变量取反，若为 1 则取原变量。

- **Maxterms**
  - 每个最大项由 $n$ 个变量的 OR 项得到，若对应二进制位为 0 则变量取原变量，若为 1 则取反。
  - 每个最大项是其对应最小项的补，反之亦然（$M_i = m_i'$）。

- **示例**：
  - $M_0 = m_0'$（$M_0' = m_0$）
  - $\Rightarrow (x+y+z)' = x'y'z'$

| $x$ | $y$ | $z$ | Minterm 项 | Minterm 编号 | Maxterm 项 | Maxterm 编号 |
|-----|-----|-----|---------------|----------------------|---------------|----------------------|
| 0 | 0 | 0 | $x'y'z'$ | $m_0$ | $x + y + z$ | $M_0$ |
| 0 | 0 | 1 | $x'y'z$ | $m_1$ | $x + y + z'$ | $M_1$ |
| 0 | 1 | 0 | $x'yz'$ | $m_2$ | $x + y' + z$ | $M_2$ |
| 0 | 1 | 1 | $x'yz$ | $m_3$ | $x + y' + z'$ | $M_3$ |
| 1 | 0 | 0 | $xy'z'$ | $m_4$ | $x' + y + z$ | $M_4$ |
| 1 | 0 | 1 | $xy'z$ | $m_5$ | $x' + y + z'$ | $M_5$ |
| 1 | 1 | 0 | $xyz'$ | $m_6$ | $x' + y' + z$ | $M_6$ |
| 1 | 1 | 1 | $xyz$ | $m_7$ | $x' + y' + z'$ | $M_7$ |

## 最小项之和（Sum-of-Minterms, SOM）

- 一个布尔函数可以从给定的真值表代数地表示：对函数值为 1 的每种变量组合构造一个最小项，然后取所有这些项的 OR。

- 右侧真值表的电路可以用 SOM 表示为：
  $$F = x'y'z + x'yz + xy'z' + xyz$$
  $$= m_1 + m_3 + m_6 + m_7$$
  $$= \Sigma(1,3,6,7)$$

- 那么 $F'$ 是使函数值为 0 的最小项之和：
  - $F' = m_0 + m_2 + m_4 + m_5$
  - $F = (m_0 + m_2 + m_4 + m_5)'$
    $$= (x'y'z' + x'yz' + xy'z' + xy'z)'$$
    $$= (x+y+z)(x+y'+z)(x'+y+z)(x'+y+z')$$
    $$= M_0 \cdot M_2 \cdot M_4 \cdot M_5$$
    $$= \Pi(0,2,4,5)$$

- **Product-of-Maxterms（POM，最大项之积）**：
  - 对函数值为 0 的每种变量组合构造一个最大项，然后取所有这些最大项的 AND。

### 规范形式之间的转换

- **规范形式**（每种形式唯一）：
  - sum-of-minterms（SOM）
  - product-of-maxterms（POM）

- 从一种形式转换为另一种形式：交换 $\Sigma$ 和 $\Pi$，并列出原形式中未包含的编号。

$$F = \Sigma(1, 3, 6, 7) = m_1 + m_3 + m_6 + m_7$$
$$F' = \Sigma(0, 2, 4, 5) = m_0 + m_2 + m_4 + m_5$$
$$F = \Sigma(1, 3, 6, 7) \quad \text{(SOM)}$$
$$= (F')' = (m_0 + m_2 + m_4 + m_5)' \quad \text{(Complement)}$$
$$= m_0' m_2' m_4' m_5' \quad \text{(DeMorgan's)}$$
$$= M_0 M_2 M_4 M_5 \quad (M_i = m_i')$$
$$= \Pi(0, 2, 4, 5) \quad \text{(POM)}$$
